# Lunar surface texture

`moon-lroc-2k.jpg`: JPEG conversion of NASA Scientific Visualization Studio's
2048 × 1024 LROC colour map. Downloaded from:
https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_poles_2k.tif

Source context: https://svs.gsfc.nasa.gov/4720/
Credit: NASA / GSFC / Arizona State University.

This global image is visual context, not a 100 m local terrain product.
The globe's displacement remains illustrative; no terrain skyline is derived.
